# 媒体服务器查询优化记录

本次基于 `05967cdc0` 实现查询内容选择，范围为 Emby、Jellyfin、Plex、Navidrome。
极空间、飞牛、绿联、Vyo 按用户要求跳过，其适配器源码无改动。

调用方使用统一的 `MediaServerQueryOptions.fields`；省略选项保留原有内容，显式空集合只取操作必需信息。
同步、查重、分集、首页、播放入口及壁纸分别声明所需内容，适配器保留身份匹配与范围过滤依赖。
完整内容组、协议映射及调用文件清单见 [查询内容契约](media-server-query.md)。

| 服务 | 主要变化 |
| --- | --- |
| Emby / Jellyfin | 按需追加 Fields，独立控制图片和用户数据；精简详情按 Ids 查询，递归及失效缓存回退保留选项 |
| Plex | 下发 excludeFields / excludeElements，按需请求 Guid / Media，避免 SDK 自动补查；原生音乐条目标识规范为字符串 |
| Navidrome | 精简列表及最新专辑使用服务端 size / offset，跳过不用的数量与封面工作；Subsonic 不提供通用字段裁剪 |

旧模块 provider 只对已登记的可选 query 参数兼容省略。未改造的四种服务继续按旧客户端签名调用，Agent 原生动作连接前拒绝它们的 query 参数。
未新增 REST 查询参数；Python 门面与 Agent 使用同一内容模型，工具 Schema 从该模型推导。
部分服务端基础属性无法裁剪，Plex 旧版本还可能忽略排除参数；本次未连接真实媒体服务器测量响应字节或耗时。
