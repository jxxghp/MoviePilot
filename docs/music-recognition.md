# 音乐专辑识别

专辑匹配不要求提供年份。普通 `year`、原始发行年 `original_year` 用于候选排名，
不单独否决名称、艺人、录音版本和曲目证据相符的专辑，以兼容首发、再版和数字发行的年份差异。
明确提供的当前发行年 `release_year` 仍是版本约束；来源年份未知时不凭空判为冲突。
MusicBrainz 具体发行 ID、发行组 ID，以及 Live、Remix 等录音版本的约束保持有效。

文件名或标签已提供歌手时，不带歌手、年份的纯专辑名目录也会补入缺失的专辑字段。
例如 `周杰伦的床边故事/周杰伦 - 告白气球.flac` 会提供“周杰伦 / 告白气球 / 周杰伦的床边故事”
三项检索线索。`Music`、`Downloads`、`音乐` 等通用目录不作为专辑名，已有标签专辑不被目录覆盖。

目录线索不等于在线身份确认。来源专辑仍须通过艺人、名称、版本和本地曲目对位校验；
不同录音或不同内容的多个合理候选仍需人工选择，不按搜索返回顺序猜测。
完整可信的本地标签可直接用于离线整理，无须先获得唯一的在线数据库 ID。
