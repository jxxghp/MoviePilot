# 整理成功通知粒度

系统设置 → 高级设置 → 实验室中的“按批次聚合整理成功通知”默认开启，
对应 `TRANSFER_SUCCESS_NOTIFICATION_AGGREGATION=true`。一张分轨专辑的任务全部结束后，
按下载器/种子、目标媒体目录、季和用户合并成一条成功通知。没有下载 hash 时按源目录分组。
音乐标题显示专辑，正文显示实际入库文件数、已知的专辑总曲目数及目标目录，
多文件通知提供“查看整理记录”入口；单文件明确批次立即发送并沿用用户通知模板。

电影、电视剧和音乐使用同一个全局开关。关闭时保持原有按媒体作业发送的行为。
目录设置继续使用原来的“发送通知”开关（`notify: true/false`），不增加通知粒度设置。
批次聚合只影响展示消息，逐文件整理历史、完成/失败事件、刮削和种子状态回写保持原流程。
失败通知仍由独立的失败聚合开关控制。

没有明确批次的外部任务采用三十秒静默窗口；连续到达会重置窗口。
明确批次等待登记关闭且所有任务终结，较慢的曲目不会打断汇总，失败任务不会计入成功文件数。
前台手动整理仍不发送成功通知。关闭进程时在整理 worker 收敛后刷新剩余缓冲。
通知缓冲是内存展示状态，异常退出不保证重发此前已完成任务的成功通知；逐文件历史仍可查询。
