# 消息渠道任务清单

导航：[设计](design.md) · [计划](plan.md) · [验证](validation.md)

| 任务 | 交付 | 状态 |
| --- | --- | --- |
| 身份隔离 | 发言人与会话分离，完整地址约束传统交互及 Agent。 | 已实现 |
| 授权与归属 | 申请、审批、关联、停用、删除及批量操作；不可变业务归属。 | 已实现 |
| 资源管理 | 连接、通知、交互独立版本；完整删除及名称释放。 | 已实现 |
| 交互规则 | 四种首次使用策略、操作范围、规则定时任务及三种自动下载模式。 | 已实现 |
| 通知规则 | 消息类型、组合通知类别、平台目标和发送窗口。 | 已实现 |
| 可靠投递 | 冻结目标与分段进度、回执及任务结果复核、Web Push 账号隔离。 | 已实现 |
| 数据库升级 | 单一重构迁移接在官方待确认下载迁移之后，保留既有公开合同。 | 已实现 |
| 最新下载链整合 | 待确认下载保留原始 owner/提交标识；既有任务不被重新认领。 | 已实现 |
| 提交前验证 | 最终源码的测试和门禁记录。 | 见验证文档 |
| 企业微信真实平台 | 未进行真实租户验收；离线用例不代替平台验收。 | 本次跳过 |
| 其他真实平台及生产部署 | 使用部署方允许的账号、群组和设备验收。 | 部署前执行 |

前端实现和界面验收由[前端任务清单](https://github.com/jxxghp/MoviePilot-Frontend/blob/v3/docs/channel-settings/tasks.md)维护。
