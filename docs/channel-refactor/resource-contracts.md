# 渠道资源基础契约

本阶段只增加无 I/O 的资源模型和纯规则计算，不切换运行中的通知配置或授权入口。

- 连接 ID 与身份空间共同限制路由归属；revision 是条件写入版本。
- 平台提供规范身份事实，规则命中只产生候选操作范围，公共授权用例仍独立复核账号、审批状态和权限。
- 通知时间按本地时间计算，含起止分钟，跨午夜窗口有效；窗口外跳过。
- `AdmissionProof` 属于宿主私有可信入口，不是插件公共 SDK，不允许从外部 JSON 反序列化为可信权限。
- 投递结果与浏览器订阅使用严格契约；浏览器地址和密钥不携带业务账号归属。

运行态装配、平台实现、持久化升级和公开管理 API 由后续依赖 PR 接入。
